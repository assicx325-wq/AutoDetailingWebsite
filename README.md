# BLACKLINE DETAILING

Адаптивный одностраничный сайт детейлинг-студии на React и Vite.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка и локальный просмотр:

```bash
npm run build
npm run preview
```

## Настройка контента

- Контакты, адрес, график, ссылки на соцсети, карта и адрес обработчика формы — `src/data.js`, объект `business`.
- Услуги, пакеты, цены и подписи к фотографиям — там же.
- Главные изображения страницы — объект `photos` в `src/data.js`.
- Фотографии галереи загружаются с Unsplash через адаптивные URL `srcset`; перед запуском замените демонстрационные изображения реальными материалами студии.
- `business.isDemo` включает заметные пометки, что цены, адрес и материалы шаблонные. Выключайте этот флаг только после замены демонстрационных данных.
- Не помещайте секреты в переменные `VITE_*`: Vite встраивает их в клиентский код. Серверные ключи должны храниться только на backend.

## Запись клиентов

Форма проверяет имя, российский номер телефона и выбранную услугу. В демонстрационном режиме `business.isDemo: true` форма никогда не отправляет и не сохраняет заявки. В рабочем режиме укажите HTTPS endpoint в `src/data.js`: сайт отправляет JSON `POST` с полями `name`, `phone` и `service`. Endpoint должен проверять данные на сервере и возвращать успешный HTTP-статус после принятия заявки.

Инструкция Cloudflare Pages находится в `DEPLOYMENT.md`. Перед публикацией добавьте политику конфиденциальности и ссылку на неё в `business.privacyPolicyUrl`, замените демонстрационные контакты, цены, фото и подписи к отзывам. В блоке отзывов сейчас только места-заполнители, вымышленных отзывов нет.
